Agent新手村 v1.0 骨架预览版 — 使用说明
========================================

⚠️ 版本性质声明
  本包为「v1.0 骨架预览版」，不是正式发布版。
  - 74 关课程内容、解锁链、存档、能力测试等全部功能可完整测试；
  - 部分素材为明确标记的 placeholder（骨架占位图），
    包括: 关卡头像 C26-C70、完成图 G26-G70、W3-W7 世界背景/Boss/认证图、
    入村插画 K01-K03（占位图上均有清晰的编号与用途标注）；
  - 正式美术将在贴皮阶段同名替换，不影响课程与进度；
  - 素材状态清单见 assets/asset_manifest.json。

一、软件名称
  Agent 新手村 v1.0 骨架预览版

二、适用用户
  零基础学习者——不需要任何编程经验。
  学完能: 理解 AI 基本概念、使用命令行、读懂代码逻辑、
  理解 Agent 工作方式、学会用 AI 工具完成任务。

三、解压方式
  将 Agent新手村_v1.0_骨架预览版.zip 解压到任意文件夹。
  解压后不要移动或删除 assets/ 文件夹——
  所有图片资源都从那里加载。

四、如何启动
  Windows: 双击解压后的「Agent新手村.html」文件即可。
  Mac: 双击或在浏览器中打开。

五、建议浏览器
  Edge 或 Chrome（最新版）。
  不支持 IE 或过旧浏览器。

六、如何保存进度
  进度自动保存在浏览器中，不需要登录或注册。
  关闭浏览器后重新打开同一个 HTML 文件，
  进度会自动恢复。

  ⚠️ 注意：
  - 进度保存在当前浏览器的当前电脑上。
  - 清除浏览器数据会丢失进度（点「重置全部进度」除外）。
  - 在不同电脑上打开不会同步进度。
  - 使用浏览器「无痕模式」不会保存进度。

七、如何重置
  打开游戏 → 底部导航 → 设置 → 点击「重置全部进度」。
  这会清除所有关卡进度、XP、星星、成就，不可恢复。

八、学习模式与路线（当前阶段说明）
  - 标准学习模式: 可正常选择。
  - 青少学习模式: 即将开放（当前不可选择，完整青少版制作中）。
  - 零基础成长线: 正式开放，按主线顺序解锁。
  - 有基础挑战线: 依赖「世界试炼」，开发中。
    能力测试的五维得分正常展示并记录进档案；
    世界试炼上线后可切换到挑战线。

九、常见问题

  Q: 打开后白屏怎么办？
  A: 确认 assets/ 文件夹和 HTML 在同一目录下。
     尝试换 Edge 或 Chrome 浏览器。

  Q: 进度丢了怎么办？
  A: 确认没有清除浏览器数据。
     确认没有使用无痕模式。
     确认打开的是同一个 HTML 文件（文件路径一致）。

  Q: 有些图片看起来是「带编号的占位图」？
  A: 这是骨架预览版的正常状态——placeholder 素材上都标有
     编号与用途，正式美术会在贴皮阶段同名替换。

  Q: 图片完全不显示？
  A: 确认 assets/ 文件夹完整，没有被移动或改名。
     确认解压时没有报错。

十、当前限制
  - 不需要联网，全部本地运行。
  - 不接入真实 AI API（所有 AI 交互为教学模拟）。
  - 这是本地单机学习版本，不支持多人或云端同步。
  - 青少学习模式与世界试炼尚未开放（见第八节）。
