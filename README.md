# Agent 新手村 · Agent Newbie Village

**面向零基础小白的 AI Agent 游戏化学习软件**

一个完全不懂终端、代码、环境、Agent 和工作流的普通人，打开浏览器就能从零学会指挥 AI。

---

## 是什么

Agent 新手村是一个**单文件 HTML 浏览器游戏**（~550KB），无需安装、无需服务器、无需注册，双击即用。

通过 8 个世界的 74 个关卡，NPC 小黑带你从 "AI 是什么" 走到 "亲手设计一条带审批、带重试、带验收的完整工作流"。

---

## 8 个世界

| # | 世界 | 关卡 | 学会什么 |
|---|------|------|---------|
| 0 | **AI 启蒙营** | 11 关 | AI 是什么、大模型、Prompt、幻觉、隐私安全 |
| 1 | **黑窗口村** | 8+1 关 | 终端命令：看位置、列文件、进目录、读内容、搜索、管道 |

| 4 | **环境工坊** | 8+1 关 | 报错排查：读报错、定位问题类型、判断修复方向、配环境 |

**70 主线 + 4 可选 = 74 关** · 8 个 Boss 战 · 8 张能力认证

## 设计理念

不走教科书路线。每个关卡遵循真实学习节奏：

```
遇到问题 → 大白话讲原理 → 动手试试 → 答错有解释 → 答对有迁移 → 学完知道"我学会了什么、能做什么、下一步为什么学那个"
```

- **零基础友好**：所有术语当面解释，没有预设知识门槛
- **真实能力产出**：不止做选择题——读代码、查报错、配置 Agent、设计工作流
- **完全离线**：纯静态 HTML，无后端、无数据库、无在线依赖
- **手机也能用**：响应式设计，480px 到 1280px 自适应

## 快速开始

### 方式一：直接打开（推荐）
```
双击 Agent新手村_R1.2-alpha2.html
```

### 方式二：克隆仓库
```bash
git clone https://github.com/329800187-design/Agent-Newbie-Village.git
cd Agent-Newbie-Village
# 打开 release/R1.2-alpha2/Agent新手村_R1.2-alpha2.html
```

不需要 `npm install`，不需要 `python -m http.server`，浏览器直接打开就能跑。

## 技术栈

- 单文件 HTML5 + 内联 CSS + 原生 JavaScript
- localStorage 存档（`agent_village_d`）
- 虚拟终端引擎（W1 黑窗口村）
- Agent 模拟运行引擎（W6 智能体工坊）
- 工作流模拟引擎（W7 工作流工场）
- 入村能力测试 + 分层学习系统
- 关卡验证器（LevelValidator）

零框架、零构建、零运行时依赖。
