# R1.2 Round4-P0 完成路径写入审计

> 审计对象：`Agent新手村_当前版.html`（基线引擎）中原始 `Level.done()` 的真实写入顺序。
> 派生链：Round2-R2 (`Agent新手村_R1.2-round2-dev.html`) → Round3 (`Agent新手村_R1.2-round3-dev.html`，注入 `round3_features.js`) → Round4-P0（在 Round3 之上注入 `completion_transaction.js` 并重排 `Level.done`）。

## 一、原始 `Level.done()` 真实写入顺序（节选自 `Agent新手村_当前版.html` 第 2205–2232 行）

```
done(){
  if(this._completing) return;          // 重入守卫
  this._completing=true;
  var id=this.current, lvl=LevelData[id], st=State.levels[id];

  // —— 引擎原生门禁（W6/W7 仅当 Sim/WfSim 存在时；缺省不拦截）——
  if(id==='w6_9' && Sim...) { ...; this._completing=false; Game.toast(...); return; }
  if(id==='w7_7')        { ...; this._completing=false; Game.toast(...); return; }

  // ===== 阶段 B：权威状态写入（原始顺序）=====
  var stars=Math.max(1,3-this.hintN);
  var _first=!st.completed;
  var _old=st.stars||0;
  st.completed=true;                                                   // [W1] 当前关 completed
  if(stars>_old){ State.totalStars+=(stars-_old); st.stars=stars; }    // [W2] stars + totalStars
  if(_first){ State.xp+=lvl.xp; }                                      // [W3] xp（仅首次）
  var _meta=getLevelMeta(id); var _isCore=...; var _nextCore=null;
  if(_isCore){ _nextCore=getNextCoreLevel(id); }
  if(_nextCore && State.levels[_nextCore]){
    State.levels[_nextCore].unlocked=true;                             // [W4] 下一关 unlocked
    if(_first) State.currentLevel=_nextCore;                           // [W5] currentLevel（仅首次）
  }
  if(_refreshUnlockedFlags) _refreshUnlockedFlags();                   // [W6] 全体 unlocked 重算（读 State，不写持久化）
  var rc=false;
  if(lvl.achievement && State.achievements.indexOf(lvl.achievement)<0){
    State.achievements.push(lvl.achievement); rc=true;                 // [W7] achievements（幂等）
  }
  if(id==='w6_9' && Sim)  Sim.clearDraft();                            // [W8] 清 W6 草稿（独立 localStorage key）
  if(id==='w7_7' && WfSim) WfSim.clearDraft();                         // [W9] 清 W7 草稿（独立 localStorage key）
  LearningLog.log('level_complete',id,'',1,false,true);               // [W10] 学习日志（append-only，非权威）
  var _payload={...}; if(w6/w7) _payload.testResults=...;
  Artifact.saveLevel(id,_payload);                                    // [W11] 作品存档（独立 localStorage key）
  State.save();                                                       // [W12] 持久化 → localStorage['agent_village_d']
  Game.starBurst();                                                   // [W13] 粒子特效（纯 UI 副作用）

  // ===== 阶段 C：展示（与阶段 B 同函数，无法分离）=====
  Game.toast(...);                                                    // [D1] 同步 toast
  setTimeout(function(){                                              // [D2] 异步展示（1400ms）
    self._completing=false;
    if(lvl.boss&&lvl.achievement){ Cert.show(...); return; }
    if(_isCore&&_nextCore&&_realUnlocked(_nextCore)){
      State.currentLevel=_nextCore; State.save(); WorldMap.refresh(); Game.startLevel(_nextCore);
    } else { WorldMap.refresh(); Game.backToMap(); }
  },1400);
}
```

## 三、关键结论

1. **权威状态字段集合**（必须纳入提交前快照与回滚）：`State.levels[id]`（当前关全部子字段）、`State.levels[_nextCore]`（若存在）、`State.currentLevel`、`State.totalStars`、`State.xp`、`State.achievements`（数组副本）、以及主存档字符串 `localStorage['agent_village_d']`。
2. **持久化入口**：`State.save()` → `localStorage.setItem('agent_village_d', JSON.stringify({schemaVersion,currentLevel,levels,xp,totalStars,achievements,peipeiFound,learnerProfile}))`。注意 `completed`/`unlocked`/`stars` 均已含在 `levels` 子树内，故「内存 + 持久化」一致性由回滚该子树 + 重写 `agent_village_d` 即可保证。
3. **非权威 / 不参与回滚**：`LearningLog`（append-only 记录）、`Artifact.saveLevel`（作品侧车）、`Sim/WfSim.clearDraft`（配置草稿侧车）、`Game.starBurst`/`Game.toast`/展示导航（纯 UI/展示副作用）。这些在回滚时**不**恢复——符合「四方一致」仅约束 `completed`/进度/门禁记录/存档的语义。
4. **`completedAt` 字段不存在**：原始引擎**不**写入 `completedAt`；「完成时间」仅以 `LearningLog.log('level_complete',...)` 的 append-only 时间戳体现，非每关字段。因此快照/回滚**不**包含 `completedAt`（无此字段可写）。若未来引入，须补入权威快照集合。
5. **重入守卫**：`this._completing` 在入口置 `true`、出口（含 `setTimeout` 内与异常路径）恢复 `false`。本轮回滚与提交逻辑必须保证**所有出口**恢复 `_completing=false`，不得遗留提交锁。
6. **阶段 B / 阶段 C 必须分离**：原始实现将权威写入（W1–W12）与展示（D1–D2）置于同一函数，导致「展示异常无法与提交解耦」。Round4-P0 在派生构建中将 `Level.done` 重排为 `_commitCompletion(id)`（W1–W12，无展示）与 `_showCompletion(id)`（D1–D2），由 `completion_transaction.js` 的新 `Level.done` 编排：先快照→门禁→`commit`→唯一成功提交点→再 `show`，从而令阶段 C 异常**不**回滚。
