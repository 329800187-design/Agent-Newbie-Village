## 三、Splash 启动页升级

**修改位置**: `#splash` div (原 line 289-297)

**新增内容**:
- 标题 "Agent 新手村"（金色发光 serif 字体）
- 副标题 "从零开始 · 学会指挥 AI"
- 三个卖点卡片：不需要安装环境 / 8世界74关卡 / 小黑带学

## 四、关卡完成弹窗升级 (Cert.show)

**修改位置**: `Cert.show()` JS 函数 (原 line 2629-2636)

**从旧版**: 图片 + 缎带 + 名称 + XP
**升级为**:
1. 徽章区 `.cc-badge`：图标 + 认证名称 + 世界名
2. 内容区 `.cc-body`：
   - 你完成了什么（关卡计数）
   - 累计经验
   - 能力认证说明
3. 操作区 `.cc-actions`：进入下一关 / 返回地图

**按钮**: 从 `.btn-primary` 改为 `.btn-gold`（金色渐变，更突出）
